# Fixtures

**All data in this directory is fictional.** The funders, recipients and grants
named here do not exist. The *shape* of the records follows the real 360Giving
Data Standard so that parsing is tested against the real format, but no value is
real data and none of it may be presented as a real funding opportunity.

Live verification against `https://api.threesixtygiving.org/api/v1/` is still
required before any claim is made about coverage. It has not been done: the build
environment's egress allowlist blocks that host.
